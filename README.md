# 🛒 Walmart Stock Application

[Java]
[React]
[TypeScript]
[Node.js]
> 📦 A powerful inventory management system for data-driven retail decisions — built for speed, clarity, and control.

**Walmart Stock Application** is a full-stack inventory dashboard that helps retailers analyze sales performance, monitor inventory health, and track profit margins — all in real-time.

Built with **Java (Swing)** on the backend and a dynamic **React + TypeScript** frontend, it empowers users with intuitive search, interactive charts, and actionable insights.

## ✨ Core Features

✅ **Real-Time Inventory Search**  
Lightning-fast search across SKUs, names, and categories with live updates.

📈 **Sales Trend Analysis**  
Visualize performance using custom-built analytics components with chart integrations.

💰 **Profit Margin Insights**  
Automatically calculate and track margins across time and product lines.

📊 **Dashboard UI**  
User-friendly, dynamic interface with responsive components built using React & Tailwind.

## 🧰 Tech Stack

| Layer        | Tools & Frameworks                                      |
|--------------|----------------------------------------------------------|
| Frontend     | [React]
| Backend      | [Java]
| UI Toolkit   | Java Swing (Desktop), Tailwind CSS (Web)                |
